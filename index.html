Go live in 2 minutes

  1. Open the repository (link above) while signed in.
  2. Click Add file → Upload files.
  3. Upload OneDesk_Coordinator_Register.html from your computer and set the name to app.html.
  4. Commit changes.
  5. Go to Settings → Pages.
  6. Source: Deploy from branch main, folder /(root) → Save.
  7. After 1–2 minutes open:
    https://mdcmkgiqac-agent.github.io/onedesk-mdc-malkangiri/app.html

Multi-device / multi-user

Every PC and phone opens the same URL. Inside the app, paste your Google Apps Script Web App URL under Google Sheet sync so all entries from all devices land in one shared Sheet.

# One Desk — MDC Malkangiri

**Coordinator & Department Academic Register** for Model Degree College, Malkangiri (Vikram Dev University).

## Live website

After GitHub Pages is enabled:

**https://mdcmkgiqac-agent.github.io/onedesk-mdc-malkangiri/**

## Features

- Coordinator cell reports (NSS, YRC, Placement, Scholarship, Sports, IQAC, NAAC, Website, Social)
- Department academic reports (Seminar, Workshop, Field Visit, Internship, Industrial Visit, Guest Lecture, etc.)
- Official MDC Malkangiri letterhead formatting for NAAC/UGC filing
- Print/PDF, annual ZIP export, Google Sheet sync
- Works on PC and mobile browsers

## Multi-device sharing

1. Open the live URL above from any college PC or phone.
2. Connect **Google Sheet sync** (Apps Script Web App URL) so every entry is archived in one shared Sheet.
3. Use **Download backup (JSON)** to move full history between browsers if needed.

Local browser storage is per-device; the Google Sheet is the shared college archive.

## Enable GitHub Pages

1. Open the repository on GitHub → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Save — site goes live in 1–2 minutes.
